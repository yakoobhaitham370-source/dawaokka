# Visual system
Mode: Operate. Reference: nine supplied mobile screenshots of dawaok.com; original brand رعاية (Riaya). Full-screen application, no marketing frame. Cairo self-hosted Arabic typography. Purple #4F46E5, indigo #3730A3, teal #08B8B4, ink #202234, off-white #F5F6FC, lavender #EEF0FF. Rounded 24–28px panels, pill tabs, line icons, restrained shadows. RTL default, mirrored LTR English. Desktop right sidebar and working grid; phone horizontally scrollable tabs, stacked content and 44px minimum controls. Clinical alerts use icon + severity text and preserve unknown status. Dialogs reserved for protected data entry and clinical review. Refill timeline closed by default. UI must prioritize real tasks and readable data.
